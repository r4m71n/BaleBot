# ربات بله — نسخه6.1.0
نمونه فعال در پیام‌رسان بله: @mioushbot 

ربات چندمنظوره برای پیام‌رسان بله، با قابلیت‌های دانلود موزیک، ویدیو یوتوب، اخبار ورزشی، هوش مصنوعی و مانیتورینگ کانال‌های تلگرام و توییتر و... 

---

## نکته مهم درباره اینترنت ایران

در شرایط اینترنت داخلی ایران، اکثر سرویس‌های خارجی غیرقابل دسترس هستند. اما پیام‌رسان بله  و API (`tapi.bale.ai`) چون وایت‌لیست هستند از داخل ایران بدون مشکل با خارج ارتباط می‌گیرند. به همین دلیل ربات‌های بله وقتی روی یک هاست یا سرور خارجی راه‌اندازی شوند می‌توانند خروجی های خود را به راحتی به سمت پیام‌رسان داخلی بفرستند.

سرویس‌هایی مثل YouTube، SoundCloud، Pinterest و Twitter فیلتر هستند، اما چون ربات روی سرور (هاست) اجرا می‌شود نه روی دستگاه کاربر، اگر هاست شما IP خارجی داشته باشد یا این سرویس‌ها را فیلتر نکرده باشد، بدون مشکل کار می‌کنند. اکثر هاست‌های اشتراکی مثل cPanel دسترسی به این سرویس‌ها را دارند. لازم به ذکر است که می‌توانید ربات را روی هاست رایگان pythonanywhere (یا موارد دیگر)نیز راه‌اندازی کنید. ولی به دلیل محدودیت های وایت‌لیست pythonanywhere ممکن است دسترسی به برخی از قابلیت‌های ربات نداشته باشید. بر فرض مثال، با هاست pythonanywhere می‌توانید ربات بله را اجرا کنید و با تلگرام ارتباط بگیرید ولی nitterهای x در دسترس نیستند(می‌توانید هرکدام از قابلیت‌های ربات که کار نمی‌کردند یا لازم نداشتید را با دستورات ربات خاموش کنید)

## قابلیت‌ها

### دانلود موزیک

**SoundCloud — دستور `/sc`**

جستجو در SoundCloud و دانلود آهنگ. ربات ابتدا سعی می‌کند از طریق API مستقیم SoundCloud (بدون yt-dlp) آهنگ را دریافت کند. اگر آهنگ به دلیل کپی‌رایت یا محدودیت فقط در فرمت HLS باشد، به صورت خودکار از yt-dlp به عنوان روش جایگزین استفاده می‌کند. اگر هیچ‌کدام موفق نشدند، ربات همان عنوان را در YT Music جستجو می‌کند و نتایج را نشان می‌دهد.

توجه: آهنگ‌هایی که زیر لیبل‌های بزرگ موزیک منتشر شده‌اند، اغلب به دلیل کپی‌رایت از SoundCloud قابل دانلود نیستند.

**YouTube Music — دستور `/ym`**

جستجو در YouTube Music یا دانلود مستقیم با لینک. از `ytsearchmusic` برای جستجوی خالص موزیکی استفاده می‌کند. پشتیبانی از پلی‌لیست با امکان دانلود تکی، zip، یا بخش‌های ۳۰تایی.

### دانلود ویدیو یوتوب

**YouTube — دستور `/yt`**

جستجو، دانلود ویدیو یا صدا. به دلیل محدودیت ffmpeg (توضیح در بخش مربوطه)، فقط فرمت‌هایی نمایش داده می‌شوند که صدا و تصویر را یکجا دارند. معمولاً کیفیت‌های ۳۶۰p، ۴۸۰p و گاهی ۷۲۰p در دسترس هستند.

دستورات مرتبط:
- `/yt query` — جستجوی عمومی
- `/yt لینک` — دانلود مستقیم با لینک
- `/ytc @channel query` — جستجو در کانال خاص
- `/ytp @channel` — دریافت پلی‌لیست‌های کانال

### دانلود فایل مستقیم

**دستور `/dl`**

دانلود هر فایل با لینک مستقیم. اگر حجم فایل از ۱۹MB بیشتر باشد، به صورت خودکار به چند پارت ۷z تقسیم می‌شود. برای باز کردن پارت‌ها در اندروید از ZArchiver و در ویندوز از 7-Zip یا WinRAR استفاده کنید.

### استخراج مقاله

**دستور `/web`**

متن اصلی مقاله را از هر صفحه وب استخراج می‌کند. از کتابخانه `readability-lxml` استفاده می‌کند.

### جستجوی تصویر

**دستور `/pin`**

جستجوی تصویر در Pinterest.

وضعیت فعلی: این بخش به دلیل تغییرات اخیر در ساختار Pinterest کار نمی‌کند. راه‌حل‌های موجود:
- استفاده از API رسمی Pinterest که نیاز به ثبت‌نام Developer دارد
- استفاده از سرویس‌های ثالث مثل SerpApi
- جستجوی تصویر از Google Images به عنوان جایگزین

### نتایج روزانه فوتبال و تنیس

**دستور `/football`**

بازی‌های فوتبال امروز از لیگ‌های اصلی اروپا شامل Premier League، La Liga، Serie A، Bundesliga، Ligue 1، Champions League، Europa League و Conference League. از ESPN API استفاده می‌کند. همچنین می‌توانید با بررسی ESPN api لیگ‌ها و یا تورنومنت‌های دیگری را نیز اضافه کنید. 

**دستور `/tennis`**

بازی‌های ATP و WTA امروز به همراه نتایج ست‌ها. از ESPN API استفاده می‌کند.

### آب و هوا

**دستور `/city`**

وضعیت آب و هوای شهر مورد نظر به همراه پیش‌بینی ۳ روزه. از سرویس wttr.in استفاده می‌کند.

### هوش مصنوعی

**پیشوند `ربات`**

پاسخ به سوال‌ها با استفاده از Gemini API گوگل. برای دریافت کلید API رایگان به Google AI Studio مراجعه کنید (`aistudio.google.com`). ربات از چند کلید به صورت چرخشی استفاده می‌کند تا محدودیت نرخ (rate limit) رایگان را دور بزند.
درحال حاضر بهترین گزینه رایگان طبق بررسی ها gemini flash 2.5 بود.

### مانیتورینگ کانال‌ها

ربات به صورت خودکار و بر اساس تایمر مشخص، کانال‌های تلگرام و اکانت‌های توییتر را بررسی کرده و پست‌های جدید را به کانال مقصد ارسال می‌کند.

**تلگرام:** از طریق scrape صفحه عمومی `t.me/s/username` پست‌ها(فقط متن و لینک پست‌ها) را دریافت می‌کند. نیازی به API تلگرام یا اکانت تلگرام ندارد. 

**توییتر:** از Nitter (نسخه متن‌باز توییتر) و فید RSS آن استفاده می‌کند. اگر توییتر کار نمی‌کند، احتمالاً instance های Nitter در لیست کد down هستند. لیست instance ها در متغیر `NITTER_INSTANCES` در ابتدای کد قابل تغییر است. برای یافتن instance های فعال به `status.d420.de` مراجعه کنید.

به دلیل دشواری  دریافت api یا کوکی های مرتبط با این دو روش از روش‌های ساده تر استفاده شد تا به راحتی به این دو پلتفرم دسترسی داشته باشید.

## محدودیت حجم فایل در بله

بله در حال حاضر ارسال فایل تا ۲۰ مگابایت را پشتیبانی می‌کند. ربات برای فایل‌های بزرگتر از سیستم multipart 7z استفاده می‌کند.

محدودیت‌های پیش‌فرض:
- موزیک (SoundCloud / YT Music): ۲۰ مگابایت
- ویدیو یوتیوب: ۲۰۰ مگابایت (multipart)
- دانلود مستقیم: ۲۰۰ مگابایت (multipart)

برای تغییر محدودیت‌ها از دستورات ادمین استفاده کنید:
```
/setlimit sc_max_mb 30
/setlimit yt_max_mb 100
/setlimit dl_max_mb 50
/setlimit multipart_max_mb 500
```

## محدودیت ffmpeg

ربات بدون ffmpeg طراحی شده تا روی هاست‌های اشتراکی که دسترسی root ندارند و ffmpeg ندارند کار کند.

تاثیر بر قابلیت‌ها:
- **یوتیوب:** فقط فرمت‌هایی که صدا و تصویر در یک فایل هستند قابل دانلود‌اند. معمولاً تا ۴۸۰p. کیفیت ۷۲۰p و بالاتر در یوتیوب صدا و تصویر را جدا ارائه می‌دهد و برای ترکیب نیاز به ffmpeg دارد.
- **متادیتا:** از mutagen برای embed کردنcover art و اطلاعات موزیک استفاده می‌شود که نیازی به ffmpeg ندارد. قابل ذکر است که بله فعلا از cover art موزیک‌ها پشتیبانی نمی‌کند. 

اگر ffmpeg در دسترس است و می‌خواهید کیفیت بالاتر داشته باشید، در تابع `_yt_get_formats` می‌توانید فرمت‌های جداگانه صدا و تصویر را هم اضافه کنید و `prefer_ffmpeg` را در `_yt_download` به `True` تغییر دهید.

## ساخت ربات در بله

برای ساخت ربات در بله مراحل زیر را طی کنید:

1. در بله، به `@BotFather` پیام دهید
2. احراز هویت با شماره موبایل، تاریخ تولد و کد ملی الزامی است
3. پس از احراز هویت، دستور فرایند ایجاد ربات را طی کنید. 
4. توکن ربات را دریافت کنید و در متغیر `BALE_TOKEN` در کد قرار دهید

**یافتن User ID کاربر یا کانال:**

در نسخه وب بله (`web.bale.ai`) وقتی یک مکالمه یا کانال را باز می‌کنید، عدد موجود در URL همان User ID یا Channel ID است. این عدد را در متغیرهای `ADMIN_ID` و `DEFAULT_TARGET_CHANNEL_ID` قرار دهید.

## راه‌اندازی

### با دسترسی کنسول (SSH)

```bash
git clone https://github.com/username/bale-bot.git
cd bale-bot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

مقادیر زیر را در ابتدای `bale_bot.py` تنظیم کنید:
```python
BALE_TOKEN = 'توکن ربات شما'
ADMIN_ID = 'آیدی عددی شما'
DEFAULT_TARGET_CHANNEL_ID = 'آیدی کانال مقصد'
GEMINI_KEYS = ['کلید اول', 'کلید دوم', ...]
```

سپس:
```bash
python3 bale_bot.py
```

برای اجرای دائمی:
```bash
nohup python3 bale_bot.py &
```

### بدون دسترسی کنسول — cPanel با Cron Job

این روش برای هاست‌های اشتراکی cPanel که دسترسی SSH ندارند طراحی شده است.

**گام ۱ — آپلود فایل‌ها**

از File Manager در cPanel فایل `bale_bot.py` را آپلود کنید.

**گام ۲ — نصب کتابخانه‌ها**

در cPanel به بخش Setup Python App بروید، یک Python App با نسخه 3.11 بسازید و کتابخانه‌ها را نصب کنید.

**گام ۳ — ساخت start_bot.sh**

یک فایل `start_bot.sh` با محتوای زیر بسازید (مسیرها را با مسیر واقعی هاست خود جایگزین کنید):

```bash
#!/bin/bash
LOCKFILE="/home/username/bale_bot.lock"
LOGFILE="/home/username/bale_bot.log"
PYTHON="/home/username/virtualenv/bale_bot/3.11/bin/python3"
SCRIPT="/home/username/bale_bot.py"

if [ -f "$LOCKFILE" ]; then
    PID=$(cat "$LOCKFILE")
    if ps -p "$PID" > /dev/null 2>&1; then
        exit 0
    fi
    rm -f "$LOCKFILE"
fi

cd /home/username
echo $$ > "$LOCKFILE"
"$PYTHON" "$SCRIPT" >> "$LOGFILE" 2>&1 &
echo $! > "$LOCKFILE"
```

**گام ۴ — تنظیم Cron Job**

در cPanel به بخش Cron Jobs بروید و یک Cron Job هر ۵ دقیقه یا هر مدت‌زمان دیگری اضافه کنید:

```
*/5 * * * * /bin/bash /home/username/bale_bot/start_bot.sh
```

این Cron Job هر ۵ دقیقه بررسی می‌کند که اگر ربات در حال اجرا نیست، آن را راه‌اندازی کند.

## مشکلات رایج

**ربات پیام‌ها را جواب نمی‌دهد ولی کانال‌ها را بررسی می‌کند**

احتمالاً یک پیام خاص باعث exception شده و پردازش آپدیت‌ها متوقف شده است. ربات را restart کنید. اگر بعد از restart دوباره همین مشکل پیش آمد، offset را در دیتابیس دستی جلو ببرید.

**چند نمونه از ربات همزمان اجرا می‌شود**

اگر lock file به درستی کار نکند، چند instance همزمان اجرا می‌شوند که باعث پردازش تکراری آپدیت‌ها می‌شود. lock file را حذف و ربات را restart کنید.

**خطای `RequestsDependencyWarning`**

این فقط یک warning است و تاثیری بر عملکرد ندارد. برای رفع آن:
```bash
pip install --upgrade requests urllib3 charset-normalizer
```

**SoundCloud آهنگ دانلود نمی‌کند**

برخی آهنگ‌های لیبل‌دار به دلیل کپی‌رایت فقط در فرمت HLS ارائه می‌شوند. ربات به صورت خودکار از yt-dlp به عنوان روش جایگزین استفاده می‌کند. اگر این هم موفق نشد، جستجو در YT Music نمایش داده می‌شود.

**توییتر کار نمی‌کند**

instance های Nitter که در کد تعریف شده‌اند ممکن است down باشند. لیست `NITTER_INSTANCES` در ابتدای کد را با instance های فعال به‌روز کنید.

**yt-dlp آهنگ یا ویدیو را دانلود نمی‌کند**

yt-dlp نیاز به به‌روزرسانی مکرر دارد:
```bash
pip install --upgrade yt-dlp
```
